## Comportamiento verificado

- Página española con título Cafetería, un h1, main enfocable y skip link. Explica que menú/pedidos aún no están disponibles; no añade fotos, formularios ni controles de negocio. Estilo funcional blanco/negro, foco visible y objetivo del enlace de salto >=44px; no animaciones. No se presenta como composición aprobada ni como AAA certificada.
- Ruta dinámica GET /api/health lee configuración del servidor en runtime. Único upstream permitido: origin exacto API_BASE_URL, protocolos HTTP(S), sin credenciales/path/query/hash. No lee URL del usuario y rechaza redirects. Conserva 200/503/versión y no-store; elimina campos fuera del contrato. Red/JSON/estado inesperado devuelve 503 con version unknown, sin copiar errores o secretos.
- El test HTTP compila Next sin variables particulares del upstream, lo inicia con URL dinámica en runtime, y verifica inicio, proxy 200 y 503, versión y no-store. Parámetro url=untrusted ignorado; redirect no seguido. Upstream HTTP técnico del arnés, no sustitución de la API de T011 (probada con Docker en su propia suite).
